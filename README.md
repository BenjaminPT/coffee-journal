# Кофейный журнал

Дневник кофе и варок по мотивам iBrewCoffee, переработанный по UI/UX. Это PWA: работает офлайн, ставится на экран телефона, данные хранятся на устройстве.

## Что умеет

| Из iBrewCoffee | Здесь |
|---|---|
| Сохранение пачек кофе (обжарщик, страна, регион, высота, ферма, сорт, обработка, обжарка, дата, вес, цена, вкус, история, фото) | Раздел «Кофе» |
| Запись варок, 60+ методов, свои методы | Журнал + «Гаджеты → Мои методы» |
| Параметры: доза, вода, пропорция, температура, помол, время, TDS, оценка SCA, рейтинг, вкусы, заметки | Форма варки |
| Оборудование и рецепты воды | Раздел «Гаджеты» |
| Умный поиск по всем полям | Поиск в журнале и в кофе |
| Сравнение варок | Кнопка «Сравнить» в журнале |
| Экспорт в PDF, Excel, резервная копия | «Ещё → Данные» |

Дополнительно: таймер варки, калькулятор пропорции (доза ↔ вода ↔ 1:N), «Повторить варку», избранное, статистика, тёмная тема, RU/EN, °C/°F, отмена удаления.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub (например, `coffee-journal`), загрузите в него все файлы этой папки (ветка `main`).
2. `Settings → Pages → Build and deployment → Source: GitHub Actions`.
3. Дождитесь зелёной галочки во вкладке **Actions**. Адрес: `https://<ваш-логин>.github.io/coffee-journal/`.
4. Откройте адрес на телефоне: Chrome → меню → «Установить приложение» (на iPhone: «Поделиться» → «На экран Домой»).

Из терминала:
```bash
git remote add origin https://github.com/<логин>/coffee-journal.git
git push -u origin main
```

## Сборка APK для Android

Во вкладке **Actions** выберите **Build Android APK → Run workflow**. Через несколько минут файл `coffee-journal.apk` будет в разделе Artifacts. Если создать тег `v1.0.0`, APK появится и в Releases.

APK подписан отладочным ключом: его можно установить напрямую (разрешите установку из неизвестных источников), но не в Google Play. Для Play нужна подпись собственным ключом.

## Локальный запуск

```bash
python3 -m http.server 8000   # затем http://localhost:8000
```
Анимации идут через [Motion](https://motion.dev) (подключается с CDN, версия закреплена). Если CDN недоступен, используется Web Animations API, и приложение работает так же.
